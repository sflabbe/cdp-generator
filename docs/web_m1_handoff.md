# WEB-M1 implementation handoff

## Implemented behavior

Complete WEB-0–WEB-5 legacy concrete vertical slice: validated inputs, canonical
JSON DTO, both kernel modes, nine interactive Plotly groups, properties with
units, raw curve tables, retained last successful calculation, and browser
JSON/XLSX downloads. The workbook retains all eight historical sheets and exact
cell contents. Existing scientific imports, CLI, file export and Matplotlib
remain available. Optional web dependencies and all packages are included in
packaging; `uv.lock` was generated by uv with working dependency resolution.

## Decisions and API

- Frozen dataclasses and Literal modes; no Pydantic or frontend framework in the contract.
- `LegacyConcreteAnalysisRequest` validates finite positive scalar inputs and
  finite non-negative rates; comma parsing errors produce readable UI messages.
- `run_legacy_concrete_analysis(request) -> ResultBundle` delegates all physics
  to the original kernel. Temperature mode passes `verbose=False` and reads
  cases from the kernel table. No adapter interpolation or numerical correction.
- `CurveSeries` supplies semantic group/quantities/units and case metadata.
  `PropertyValue` retains legacy units, including `l0` in metres.
- Schema `1.0`; `to_dict` and `to_json` provide deterministic strict finite JSON.
  Provenance is `legacy_v1`, with no EC2/fib curve authority.
- `build_figures` and `figure_for_group` consume DTOs outside Streamlit.
- `result_excel_bytes` reconstructs only export inputs in an internal adapter;
  `build_excel_bytes` owns shared workbook logic and `export_to_excel` writes it.
- Compact single-page Streamlit app; form submission and session-state result.
  The displayed input summary always identifies the last successful result.
- `[web]` keeps Plotly and Streamlit optional for base scientific consumers.
- Root-script lint corrections preserve expressions, branch semantics and zip
  truncation; unused calculated locals use underscore names. No package kernel
  or frozen baseline changes. No commits, pushes or tags were made.

## Remaining scope and limitations

No tests were left unexecuted and no dependency-resolution limitation remains.
Smoke coverage uses AppTest plus server health; no manual browser/pixel review
was performed. Existing kernel applicability and historical grid/reference
semantics remain unchanged. Inputs that cause non-finite kernel output are
rejected at serialization, without replacing values. No new material validity
range or authority qualification is claimed.

Authority-aware curve synthesis, CDPM2, steel, comparison workspace, persistence,
authentication, FastAPI and TypeScript remain outside this milestone.
